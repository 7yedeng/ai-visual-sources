# AI Visual Sources

AI 生图、视频与提示词的上游渠道目录。这里保存链接、分类和来源标记，按需回到上游查看实例、图片和提示词。

原博客的 AI 影像库已转为归档入口：[anagnoraxis.com/research/ai-visual](https://anagnoraxis.com/research/ai-visual/)。本目录承接渠道导航；图片镜像、提示词全文、案例数据库与自建向量检索停止维护。

当前收录 **82 个渠道：9 个 GitHub 仓库、1 个产品入口、72 个作者入口**。分类是本目录的编辑判断，不代表上游只包含这一类内容。GitHub 仓库的公开状态已于 **2026-11-02** 通过官方 API 核对；产品与 X 链接保留原始出处，未在本次逐页重新核验。

## 查找与 AI 使用

- 人工浏览：按上方分类进入上游。先选图像或视频，再到相应仓库内找模型名、用途或风格。
- 查目录：打开 [sources.json](sources.json)，使用浏览器查找关键词，例如 `Seedance`、`GPT`、`Skill`。GitHub 代码搜索在索引可用后也可使用 `repo:7yedeng/ai-visual-sources Seedance`。
- 给 AI 使用：让已有的 GitHub 连接器或 [GitHub 官方 MCP](https://github.com/github/github-mcp-server) 读取 `README.md` 和 `sources.json`，选出相关上游后再按需读取。可直接复制 [AI_USAGE.md](AI_USAGE.md) 中的任务示例。

这套方式无需运行本项目的服务器、定时采集器或向量数据库。GitHub 的文件和关键词搜索，加上 AI 对选定来源的理解，适合轻量查找；它不提供原影像库的全量案例语义检索。

## 维护方式

增加渠道时，编辑 `sources.json` 的一条记录，并在 README 对应分类补上链接。保留上游 URL、简短用途和出处；核验时只更新实际检查过的日期与状态。失效渠道可标记为不可用或删除，修改历史由 Git 保存。

本仓库只发布本目录的链接与说明。上游图片、视频、提示词和代码的使用条件由各自作者及项目规定；需要具体内容时请回到原出处。目录不收集访客 Cookie，也不运行自建 API、MCP、追踪或图片代理。
